## Scope requiring review

The static argument assumes the exact reviewed normally linked synchronous host. It excludes asynchronous exception injection, instrumentation or boot-class replacement, and state corruption outside the controlled boundaries. It does not byte-match Android boot libraries, run this video body on ART, build a full APK, or establish complete application equivalence.

There is no generic ignored-offset list or entry point for applying this calculation to an arbitrary method, fresh report or runtime. The existing 1,242-body active registry is unchanged. Parent review of this concrete source, its bound inputs and actual controls is required before future active integration.
