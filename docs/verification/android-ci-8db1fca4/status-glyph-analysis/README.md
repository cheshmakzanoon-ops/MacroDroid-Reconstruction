# Status-bar pixel difference in the active numeric Android run

This read-only addendum preserves the ten original screenshot identities and computes whole-frame pixel differences again. It then compares every RGBA pixel in a fixed diagnostic status-bar region and tests whether its entire foreground is exactly related by an integer translation. It does not crop, edit, regenerate, interpolate or mask either screenshot. All region pixels are retained losslessly for review.

The result records the measured translation candidates, foreground counts and remaining full-frame differences for each of the five screens. This is a spatial description of the recorded pixels. It identifies neither the status glyph's system cause nor an application cause. The original Android comparison remains a failure, and this addendum grants no parity credit. The indicator diagnostic runs separately with its own deliberately fixed earlier candidate.
