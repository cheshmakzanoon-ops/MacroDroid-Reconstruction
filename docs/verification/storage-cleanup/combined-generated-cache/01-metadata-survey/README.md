# Read-only generated-cache metadata survey

This closed survey observed 266,150 file paths in exactly eight named directories
of the old combined build. It read filesystem metadata without reading file
payloads, following symlinks, deleting files or changing source. The compressed
JSONL retains sizes, allocation, modes, link counts and physical identities.

The survey alone grants no duplicate eligibility or retirement authority. The
71,267-file hybrid-smali directory is a candidate for a separate exact comparison
against canonical source and the already published source archive. All 605
recovered classes and every nonidentical, nonregular or multilink file must be
protected by that later assessment.

The signed-edit-probe directory mixes source, tools, APKs, evidence and generated
caches. Its per-path allocated total includes hardlink duplication; the smaller
unique-inode total is recorded separately. No whole-tree retirement is proposed.
Java host classes, tool classes, the hybrid classes3 DEX, source, reports, APKs
and other control artifacts remain protected.
